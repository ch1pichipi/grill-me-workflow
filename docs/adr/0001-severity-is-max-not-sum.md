# 违规等级取最大值，而不是累加

一条消息的违规等级等于它命中的规则中**最高**的 severity（1–5）；命中多条不同规则时 +1，封顶 5。命中规则的条数与累积值只作为人工复核的辅助信号，**不参与自动处置**。

选择取最大值而非累加，是因为等级这个数字会同时出现在规则定义、语料库、惩罚阶梯和 UI 四处，它必须稳定、可解释、可审计——"这条消息命中了 4 级规则"能一句话说清，而"这条消息累计 7 分所以降为 3 档"不能。累加还有两个具体风险：规则密度会直接决定惩罚力度（多加几条低等级规则，同样的句子就会被自动重罚），以及给刷分留了入口。

代价是损失了"多条轻微违规叠加起来也很严重"的表达力。这部分表达力由违规历史（滚动 7 天计数）和人工复核补回来，而不是让等级本身承担。

**不要**在没有重新评估这两条理由的情况下改成累加。
