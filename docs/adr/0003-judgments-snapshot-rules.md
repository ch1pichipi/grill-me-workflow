# 判定存规则快照，而不是规则 id

一条判定记录它命中规则的**当时**内容：规则 id、当时的 severity、当时的模式文本、当时的视图。读取判定时不从当前语料库回查规则。

语料库可变，判定不可变。只存规则 id 会让历史判定随语料库一起漂移：管理员把一条规则的 severity 从 2 改成 5，历史上所有旧判定就追溯变重；而处置档位是根据违规历史**现算**的，历史判定的 severity 一漂，永久禁言的门槛就跟着漂——这类偏差不会报错，只会让某些玩家莫名其妙被永久禁言。

存快照让"当时判得多重"和"现在规则是什么"成为两个独立的事实，顺带也能回答"这条规则变过几次、影响过谁"。

**不要**把判定改成只引用规则 id 来省空间：语料库是几百条量级，快照的存储成本可以忽略。
